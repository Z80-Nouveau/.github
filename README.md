# Z80-Nouveau

This is the home of the Z80-Nouveau project.

There is a [Youtube Playlist](https://www.youtube.com/playlist?list=PL3by7evD3F52rUbThUNDYGxNpKFF1HCNT) that discusses the development of this project.

# Getting Started

The software and hardware for this project can be developed on a Raspberry PI or similar Unix/Linux system.
(Note that this project only uses a PI to program the FPGA.  But that can be done with a JTAG cable if you are familiar with doing so.)

- Configure a new Raspberry PI to host everything: [raspberry-pi-install](https://github.com/johnwinans/raspberry-pi-install)
- Install the Z80-Nouveau project: [nouveau-install](./nouveau-install.md)
